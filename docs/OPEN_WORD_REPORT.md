# Opening a Word Report Template

VS Code can list a `.docx` file, but use Microsoft Word or another instructor-approved word processor to edit it.

1. In the VS Code Explorer, expand the folder for the current lab.
2. Find the `Lab##_Report_Template.docx` file named in the lab README.
3. Right-click it and choose:
   - **Reveal in File Explorer** on Windows;
   - **Reveal in Finder** on macOS; or
   - **Open Containing Folder** on Ubuntu.
4. Double-click the template in the folder that opens.
5. Choose **File -> Save As** and create a personal copy such as `LastName_Lab##_Report.docx`.
6. Enter the requested results, plots, and screenshots in the personal copy.

Do not edit a Word file as text inside VS Code. Submit the personal copy specified by the lab instructions.
